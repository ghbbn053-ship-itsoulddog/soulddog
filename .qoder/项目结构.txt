📋 项目完整描述与配置文档
🎯 项目概述
项目名称：校园AI助手系统 (Edu AI Assistant / SouldDog)项目定位：基于教务系统数据爬取 + AI大语言模型的校园智能问答系统，支持课表查询、成绩查询、培养方案解析、考试安排等教务数据的智能问答。

标准推送命令：
bash
git push origin main
🏗️ 技术栈
前端
框架：Next.js 16.1.1 (App Router)
核心：React 19.2.3
语言：TypeScript 5
UI组件：shadcn/ui (基于 Radix UI)
样式：Tailwind CSS 4
包管理器：pnpm（严禁使用 npm/yarn）
运行端口：5000
后端
框架：FastAPI 0.115.6
语言：Python 3.11+
ASGI服务器：Uvicorn 0.32.1
运行端口：8000
AI/ML
大模型：通义千问 (qwen-plus) via DashScope
向量数据库：Milvus v2.4.1
RAG框架：LangChain 0.3.14
MCP协议：mcp 1.6.0 (Model Context Protocol)
数据存储
关系数据库：PostgreSQL 15 (端口 5432)
缓存：Redis 7 (端口 6379)
对象存储：MinIO (端口 9000/9001)
元数据存储：etcd v3.5.5 (端口 2379)

⚠️ 重要注意事项
热重载规则
✅ 只需 restart：修改 Python/TypeScript 代码文件
❌ 需要 --build：修改 Dockerfile、requirements.txt、package.json
❌ 需要 --build：添加新的依赖包
✅ 自动生效：代码保存后几秒内自动重新加载
Git同步规则
⚠️ Linux服务器必须手动 git pull（Docker不会自动拉取）
⚠️ 推送前需配置代理（Windows网络受限）
⚠️ 不要提交：__pycache__/、*.pyc、.next/、node_modules/
包管理器
✅ 前端必须使用 pnpm
❌ 严禁使用 npm 或 yarn
数据库迁移
PostgreSQL 表结构变更需执行 ALTER TABLE 或重建
Milvus Collection 需确保加载状态
